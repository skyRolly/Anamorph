Anamorph — Linux installation / Linux 安装说明
=============================================

The x86_64 Linux ZIP contains / x86_64 Linux 压缩包内容:
  Anamorph.vst3/   VST3 audio plug-in / VST3 音频插件
  Anamorph         portable Standalone application / 便携独立程序
  install.sh       VST3 installer / VST3 安装脚本
  uninstall.sh     VST3 uninstaller / VST3 卸载脚本
  INSTALL.txt      these instructions / 本说明

The scripts install only VST3. Standalone runs from the extracted folder; it is
not copied to a bin directory. No desktop launcher, icons or AppStream metadata
are installed. Extracting the ZIP installs nothing.
脚本仅安装 VST3。独立程序从解压目录运行,不会复制到 bin 目录。
不安装桌面启动器、图标或 AppStream 元数据。仅解压 ZIP 不会安装任何文件。

Install / 安装
--------------
From the extracted folder, run / 在解压目录中运行:
  sh ./install.sh

Choose / 选择:
  1) Current user (recommended) / 当前用户(推荐)
     ~/.vst3/Anamorph.vst3
     No root or password needed / 无需 root 或密码
  2) System-wide / 系统级
     /usr/lib/vst3/Anamorph.vst3
     The script calls sudo as needed / 需要时由脚本调用 sudo

Enter selects 1. To answer up front / 回车选择 1。也可以直接指定:
  sh ./install.sh --user
  sh ./install.sh --system

Running as root selects system-wide mode. --user is refused under root because
sudo configurations differ in which HOME they use. Run --user without sudo.
The installer sets the installed plug-in executable permission itself. No
separate chmod/chown or icon-directory permission repair is required.
以 root 运行时选择系统级模式。用户级安装请勿使用 sudo。脚本自动设置已安装插件
的执行权限,无需单独运行 chmod/chown 或修复图标目录权限。

Remove / 卸载
-------------
  sh ./uninstall.sh --user
  sh ./uninstall.sh --system

With no option the script offers the same choice. User and system installations
are independent; removing one leaves the other. Settings and presets are kept.
If an interrupted install parked an old VST3, uninstall keeps it and prints its
location. Re-run install.sh in the same mode to recover it. --discard-parked
explicitly permits removal of that saved copy.
不指定选项时会询问安装模式。用户级和系统级副本相互独立。保留设置与预设。
若中断的安装留下旧插件备份,卸载时会保留并提示位置。用相同模式重新安装即可
恢复;仅在明确要删除备份时使用 --discard-parked。

Updating an earlier 0.10.0 package / 更新早期 0.10.0 安装
------------------------------------------------------
Run the corrected scripts in the original mode to update or remove VST3.
Legacy desktop launchers, icons, ownership receipts and previously installed
Standalone applications (including staging copies) are left untouched. Remove
any unwanted legacy files manually.
以原来的模式运行修正后的脚本以更新或卸载 VST3。旧桌面启动器、图标、所有权收据
及已安装的独立程序(含暂存副本)均保留。如不再需要,请手动删除旧文件。

Rescan / 重新扫描
----------------
Restart or rescan plug-ins in your DAW. ~/.vst3 and /usr/lib/vst3 are standard
VST3 locations. If Anamorph appears twice, remove the unwanted user/system copy.
在宿主中重新扫描插件或重启宿主。若重复显示,请卸载不需要的用户级或系统级副本。

Troubleshooting / 常见问题
-------------------------
- System mode requires sudo access, or an already-root shell. User mode never
  elevates writes to HOME. / 系统级模式需要 sudo 或 root;用户级模式不会提权写入 HOME。
- Linked/foreign plug-in destinations and unknown installer scratch are
  preserved with a diagnostic. No shared directory is recursively chmodded or
  chowned. / 链接、外来插件目标或未知暂存内容会保留并提示,不会递归修改共享目录权限或所有者。
- Run scripts through sh if archive transport lost their executable bits.
  / 若解压后脚本缺少执行权限,请按上面的 sh 命令运行。
- Portable Standalone needs a working ALSA/JACK/PipeWire audio setup.
  / 便携独立程序需要可用的 ALSA/JACK/PipeWire 音频环境。
